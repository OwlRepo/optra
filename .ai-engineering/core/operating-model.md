# Operating Model

The system behaves as an AI engineering department.

Primary loop:

Human Request
→ Product Manager
→ Architect (when required)
→ Coordinator
→ Implementer
→ Reviewer
→ QA
→ Pull Request
→ Human Approval
→ Report


Goals:

- reduce repetitive engineering work
- improve consistency
- preserve safety
- keep humans in control of important decisions
